# Project Overview

This is the code for **FTC BIOBUZZ, 2026 season**, for a catapult robot.

## Robot hardware

Hardware-map names are listed exactly as configured on the robot.

### Drivetrain (mecanum)

Four GoBilda 5202/3/4 series motors:

| Name          | Position    |
|---------------|-------------|
| `front_left`  | Front left  |
| `front_right` | Front right |
| `back_left`   | Back left   |
| `back_right`  | Back right  |

### Intake

Two GoBilda 5202/3/4 series motors:

| Name           | Side  |
|----------------|-------|
| `left_intake`  | Left  |
| `right_intake` | Right |

### Catapult shooter

Two GoBilda 5202/3/4 series motors:

| Name            | Side  |
|-----------------|-------|
| `left_shooter`  | Left  |
| `right_shooter` | Right |

### Flower helper

Helps the intake pick up from a flower. Uses two Axon servos with encoders, set to position mode.

| Name           | Side  |
|----------------|-------|
| `left_flower`  | Left  |
| `right_flower` | Right |
